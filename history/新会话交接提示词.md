**沙箱编译方法**（重要，新会话需要重建这套环境才能验证 WPF 工程）：
沙箱只有 .NET 6 SDK，无法直接 build `net8.0-windows`。我用的办法是：

1. 从华为云 NuGet 拉参考程序集（微软官方源在沙箱内被墙）：
   ```
   BASE=https://repo.huaweicloud.com/artifactory/api/nuget/v3/nuget-remote
   curl -sS "$BASE/microsoft.windowsdesktop.app.ref/8.0.29/microsoft.windowsdesktop.app.ref.8.0.29.nupkg" -o wd.nupkg
   curl -sS "$BASE/microsoft.netcore.app.ref/8.0.29/microsoft.netcore.app.ref.8.0.29.nupkg" -o nc.nupkg
   unzip -q wd.nupkg -d /tmp/refs/wd && unzip -q nc.nupkg -d /tmp/refs/nc
   ```
   参考程序集位于 `/tmp/refs/{wd,nc}/ref/net8.0/*.dll`

2. 用 Roslyn 直接编译（绕过 MSBuild 的 Windows 检查）：
   ```
   dotnet /usr/share/dotnet/sdk/6.0.301/Roslyn/bincore/csc.dll \
     -target:library -langversion:latest -nullable:enable \
     -out:MCLCS.App.dll <所有 ref dll> -r:MCLCS.Core.dll \
     globalusings.cs xaml_stub.cs <所有 .cs>
   ```

3. **必须手工模拟 SDK 隐式 using**，否则误报一片。规则：
   - 基础：System, Collections.Generic, IO, Linq, Net.Http, Threading, Threading.Tasks
   - `UseWPF=true` 会 **移除** System.IO 和 System.Net.Http（这是很多 CS0246 的根因）
   - 本项目已移除 UseWindowsForms，所以不注入 System.Drawing / System.Windows.Forms

4. **XAML partial 桩**：扫描 .xaml 里的 `x:Class` 和 `x:Name`，生成 partial 类字段
   + 空的 `InitializeComponent()`，否则会有几十条 CS0103 噪声。
