总览

层次状态
Core 逻辑层覆盖度高，约 85% 规格已有对应实现
App UI 层明显落后于 Core，大量已完成的 Core 能力没有界面入口
主要矛盾不是缺算法，是缺接线 —— Core 写好了，UI 没接

一个典型例证：LauncherProfile 里 TabTheme / Hud / Prewarm / Backup / ServerPackCacheMb / AutoRepairResourcePacks / AfkWorkflows / ShaderTokens 字段全部已定义，而 SettingsViewModel 对这些字段的引用数为 0。数据模型已铺好路，纯缺绑定。
