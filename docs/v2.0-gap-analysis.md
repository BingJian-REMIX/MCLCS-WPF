> 接口实测（2026-08-03）：
> - 搜索：`GET /api/open/v1/maps/search?keyword=&category=&version=&page=&limit=&sort=`（返回 `items/total/page/limit/sort`）

> - 分类：`GET /api/categories`；版本：`GET /api/versions`
